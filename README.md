# 🏪 SKM INTEGRATE POS & ERP System

ប្រព័ន្ធគ្រប់គ្រងការលក់ (Point of Sale) និង ERP ដែលមានលក្ខណៈទម្ងន់ស្រាល (Lightweight) ដំណើរការលើ Web Browser ដោយផ្ទាល់ គាំទ្រការទូទាត់ជារូបិយប័ណ្ណពីរ (KHR / USD) ការព្រីនវិក្កយបត្រកម្តៅ (Thermal Printing) និងការរក្សាទុកទិន្នន័យលើ LocalStorage រួមទាំង Cloud Database (Supabase)។

---

## ✨ លក្ខណៈពិសេសចម្បង (Key Features)

* 💵 **Dual-Currency Support:** គណនា និងទូទាត់ប្រាក់ជាប្រាក់រៀល (KHR) និងប្រាក់ដុល្លារ (USD) ដោយស្វ័យប្រវត្តិតាមអត្រាប្តូរប្រាក់ជាក់ស្តែង។
* 🖨️ **Thermal Receipt Printing:** រៀបចំទម្រង់វិក្កយបត្រស្អាត និងអាចបញ្ជាព្រីនទៅកាន់ម៉ាស៊ីនព្រីនវិក្កយបត្រ (Thermal Printer) បានភ្លាមៗ។
* 💾 **Hybrid Data Storage:**
  * **Offline First:** រក្សាទុកទិន្នន័យលើ Browser តាមរយៈ LocalStorage ដំណើរការបានទោះគ្មានអ៊ីនធឺណិត។
  * **Cloud Sync:** ភ្ជាប់ទៅកាន់ **Supabase** ដើម្បី Sync និង Backup ទិន្នន័យលើ Cloud ប្រកបដោយសុវត្ថិភាព។
* 📱 **Telegram Bot Integration:** ផ្ញើការជូនដំណឹង (Alerts/Notifications) ទៅកាន់ Telegram Group/Channel ដោយស្វ័យប្រវត្តិរាល់ពេលមានប្រតិបត្តិការលក់។
* 🧩 **Extensible Architecture:** អាចបន្ថែម Plugin ឬ Module ថ្មីៗដោយប្រើ JavaScript Custom Extension។
* ⚡ **Single-File Architecture:** ងាយស្រួល Deploy និងបើកដំណើរការភ្លាមៗ មិនត្រូវការដំឡើង Environment ស្មុគស្មាញ។
